# Сбор данных о фильмах с КиноПоиска

## О проекте

Небольшой проект по сбору данных о фильмах с помощью API КиноПоиска.

Задача — получить информацию о фильмах жанра **«комедия»**, выпущенных в **2000 году**, отсортированных по убыванию рейтинга КиноПоиска.

## Задача

Необходимо собрать до **1000 фильмов** с наибольшим рейтингом КиноПоиска.

Для каждого фильма сохраняется:

* название;
* длительность;
* страна-производитель;
* рейтинг КиноПоиска.

Если количество подходящих фильмов меньше 1000, собираются все доступные фильмы.

Результат сохраняется в формате **JSON**.

## Используемые инструменты

* **Python**
* **Requests** — отправка HTTP-запросов и получение данных через API;
* **JSON** — обработка и сохранение полученных данных в формате JSON.

## Безопасность

URL API и токен авторизации **не включены в репозиторий**.

## Результат

Создан Python-скрипт, который автоматически получает данные о подходящих фильмах через API, отбирает необходимые записи, сортирует их по рейтингу и сохраняет результат в JSON-файл.

## Структура проекта


* `comedies_kinopoisk.py` — скрипт для сбора данных.
* `result_comedies_kinopoisk.json` — результат работы скрипта.
* `README.md` — описание проекта.
