# Анализ сообществ ВКонтакте для размещения рекламы

## О проекте

Проект по сбору и анализу данных сообществ социальной сети **ВКонтакте** для рекламного продвижения цветочного бизнеса в Омске.

Основная задача — программно найти сообщества, потенциально подходящие для размещения рекламы, и сформировать структурированный список с информацией об их аудитории и контактами.

## Бизнес-задача

Определить сообщества Омска, в которых может быть выгодно размещать рекламу цветочного бизнеса.

Для поиска используются ключевые слова:

* `цветы`;
* `флористика`;
* `магазин цветов`.

Сообщества сортируются по количеству подписчиков в порядке убывания, что позволяет в первую очередь оценить наиболее крупные площадки.

## Собираемые данные

Для каждого сообщества формируется следующая информация:

* `id` — идентификатор сообщества;
* `name` — название сообщества;
* `description` — описание;
* `is_closed` — статус сообщества (открытое или закрытое);
* `members_count` — количество подписчиков;
* `contacts` — доступные контактные данные сообщества.

Поиск выполняется только среди сообществ, связанных с городом **Омск**.

## Ход работы

1. Получение ID города через API ВКонтакте.
2. Поиск сообществ по заданным ключевым словам.
3. Получение дополнительной информации о найденных сообществах.
4. Извлечение контактных данных из доступных полей сообщества.
5. Формирование итогового набора данных.
6. Сохранение результатов в CSV-файл.
7. Проверка полученного файла: количество записей, первые строки и наличие дубликатов.

## Используемые инструменты

* **Python** — сбор и обработка данных;
* **Requests** — отправка запросов к API ВКонтакте;
* **JSON** — обработка ответов API;
* **CSV** — сохранение результатов;
* **Regular Expressions (re)** — поиск контактных данных в текстовых полях;
* **Pandas** — проверка и анализ полученного CSV-файла.

## Безопасность

Access Token для API ВКонтакте **не включён в опубликованный код**.

## Результат

Создан Python-скрипт, который программно находит сообщества Омска по заданным ключевым словам, собирает информацию о них и сохраняет результаты в CSV-файл.

Полученный датасет может использоваться для дальнейшей оценки рекламных площадок и выбора сообществ для размещения рекламы цветочного бизнеса.


* `vk_flowers_api.py` — скрипт для поиска и сбора данных о сообществах.
* `omsk_vk_groups.csv` — результат работы скрипта.
* `README.md` — описание проекта.
