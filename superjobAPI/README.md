# Сбор вакансий аналитиков с SuperJob

## О проекте

Небольшой проект по сбору и обработке данных о вакансиях с сайта **SuperJob**.

Задача — получить информацию обо всех вакансиях за последнюю неделю по ключевому слову **«Аналитик»** и сохранить результаты в структурированном CSV-файле.

## Задача

Необходимо собрать по каждой найденной вакансии следующие данные:

* ссылка на вакансию;
* название вакансии;
* название работодателя;
* город;
* заработная плата;
* заработная плата от;
* заработная плата до;
* должностные обязанности;
* дата публикации;
* признак того, является ли вакансия архивной.

Полученные данные сохраняются в формате **CSV**.

## Используемые инструменты

* **Python** — сбор и обработка данных;
* **Requests** — отправка HTTP-запросов;
* **JSON** — обработка полученных данных.

## Результат

Создан Python-скрипт, который собирает данные о вакансиях по запросу «Аналитик», опубликованных за последнюю неделю, формирует единый набор данных и сохраняет его в CSV-файл.



* `superjobAPI.py` — скрипт для сбора данных о вакансиях.
* `vacancies_analytics.csv` — результат работы скрипта.
* `README.md` — описание проекта.
