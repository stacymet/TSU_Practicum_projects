# Сбор данных о работодателях Алтайского края с HeadHunter

## О проекте

Небольшой проект по сбору и обработке данных с сайта **HeadHunter**.

Задача — получить информацию о работодателях Алтайского края, у которых на момент сбора данных есть открытые вакансии, и сохранить результаты в структурированном CSV-файле.

## Задача

Необходимо собрать данные о **1000 работодателях** с открытыми вакансиями:

* `id` — идентификатор работодателя;
* название работодателя;
* ссылки на открытые вакансии;
* количество открытых вакансий.

Полученные данные необходимо отсортировать по количеству открытых вакансий **от большего к меньшему** и сохранить в формате **CSV**.

Если подходящих работодателей меньше 1000, собираются все доступные данные.

## Используемые инструменты

* **Python** — сбор и обработка данных;
* **Requests** — отправка HTTP-запросов;
* **JSON** — обработка полученных данных;
* **Pandas** — структурирование и сохранение данных в CSV.

## Особенности проекта

Для выполнения проекта **не требуется регистрация приложения и API-токен**.

Данные получаются непосредственно с сайта HeadHunter с помощью HTTP-запросов.

## Результат

Создан Python-скрипт, который собирает данные об открытых вакансиях и работодателях Алтайского края, сортирует работодателей по количеству вакансий и сохраняет результат в CSV-файл.
