# Получение текущей погоды через WeatherAPI

## О проекте

Небольшой проект по работе с **REST API** на Python.

Задача — отправить запрос к сервису WeatherAPI и получить данные о текущей погоде в Томске.

## Задача

С помощью метода `/current.json` получить и вывести в консоль:

* название города;
* текущую температуру воздуха в °C;
* температуру, ощущаемую как, в °C.

## Используемые инструменты

* **Python**
* **Requests** — отправка HTTP-запросов к API;
* **WeatherAPI** — источник данных о текущей погоде;
* **JSON** — обработка ответа API.

## Результат

Создан Python-скрипт, который отправляет запрос к WeatherAPI, извлекает необходимые данные из JSON-ответа и выводит информацию о текущей погоде в консоль.

Пример результата:

```text
Город: Томск
Температура воздуха: 18°C
Ощущается как: 17°C
```

## Безопасность

API URL и ключ авторизации **не включены в опубликованный код**.

В рабочем коде URL и API-ключ передаются отдельно.
