# Исследовательский анализ и подготовка данных о вакансиях

## О проекте

Проект посвящён исследовательскому анализу и подготовке данных о вакансиях нефтехимической отрасли волгоградской области для дальнейшего изучения рынка труда.

В работе проведён первичный анализ набора данных, выполнена очистка и стандартизация информации о вакансиях и работодателях, а также сформирован датасет для последующего анализа.

## Основные задачи

* изучить структуру и качество исходных данных;
* проанализировать распределение вакансий по источникам;
* исследовать распределение заработных плат;
* выявить и обработать пропущенные значения;
* привести данные к необходимым типам;
* обработать и стандартизировать значения категориальных признаков;
* преобразовать данные о видах экономической деятельности (ОКВЭД);
* очистить датасет от вакансий, не относящихся к исследуемой отрасли;
* сформировать набор уникальных работодателей для дальнейшего анализа.

## Работа с данными

В рамках подготовки данных выполнены:

* анализ пропусков и явных дубликатов;
* приведение идентификаторов работодателей к строковому формату;
* обработка пропущенных значений с учётом логики предметной области;
* преобразование строковых представлений списков ОКВЭД в структурированный формат;
* унификация категорий размера бизнеса работодателей;
* фильтрация вакансий по заданному перечню профессий;
* формирование отдельного набора уникальных компаний по названию, ИНН и ОКВЭД.

## Исследовательский анализ

Проведён анализ:

* распределения вакансий по источникам данных;
* распределения значений заработной платы;
* выбросов и особенностей распределения заработных плат.

Для анализа распределений использовались гистограммы и диаграммы размаха.

## Используемые инструменты

* **Python** — обработка и исследовательский анализ данных;
* **Pandas** — очистка, преобразование, фильтрация и группировка данных;
* **NumPy** — работа с числовыми данными и пропущенными значениями;
* **Matplotlib** — визуализация данных;
* **Seaborn** — построение статистических графиков;
* **Ast** — обработка структурированных значений, представленных в строковом формате.

## Результат

В результате подготовлен очищенный и стандартизированный набор данных о вакансиях и работодателях, пригодный для дальнейшего анализа.

Проведённая предобработка позволила:

* устранить технические проблемы в исходных данных;
* привести признаки к единому формату;
* сократить количество нерелевантных вакансий;
* выделить уникальных работодателей;
* подготовить данные для последующего анализа отраслевых вакансий и работодателей.

* `research_analysis.ipynb` — Jupyter Notebook с исследовательским анализом и подготовкой данных.
* `README.md` — описание проекта.
