# Анализ выручки мобильной игры

## О проекте

Аналитический проект по исследованию выручки и пользовательской активности в мобильной игре.

В работе проведена декомпозиция ключевых метрик для поиска причин изменения выручки. Анализ выполнен в различных разрезах: по странам, рекламным каналам, продуктам и пользовательским сегментам.

## Цель исследования

Выявить аномалии в динамике выручки и определить факторы, которые могли повлиять на изменение ключевых показателей игры.

## Основные задачи

* проанализировать динамику выручки;
* рассчитать и исследовать ключевые продуктовые метрики;
* определить причины изменения выручки с помощью дерева метрик;
* выявить изменения в поведении пользователей из отдельных стран;
* исследовать динамику продаж отдельных продуктов;
* проанализировать приток новых пользователей;
* оценить эффективность рекламных каналов;
* применить модель **Last Click Attribution** для распределения новых установок по рекламным каналам;
* визуализировать результаты анализа;
* сформулировать рекомендации на основе выявленных проблем.

## Используемые данные

Для анализа использованы четыре таблицы базы данных:

* `transactions` — информация о транзакциях и выручке;
* `sessions` — данные об игровых сессиях;
* `user_info` — характеристики пользователей;
* `users_touches` — маркетинговые касания пользователей.

## Ход исследования

### 1. Анализ динамики выручки

Рассчитана общая дневная выручка и проведена её детализация по странам для выявления источников изменения показателя.

### 2. Декомпозиция выручки

Для поиска причин изменения выручки рассчитаны показатели:

* **DAU** — количество активных пользователей;
* **ARPDAU** — средняя выручка на активного пользователя;
* **ARPPU** — средняя выручка на платящего пользователя;
* **Daily Conversion** — доля платящих пользователей среди активных;
* количество возвращающихся пользователей;
* выручка от возвращающихся пользователей.

Метрики исследованы в динамике и в разрезе стран.

### 3. Анализ продуктовой выручки

Проведён анализ выручки по продуктам и ценовым сегментам пользователей для выявления изменений в продажах отдельных категорий продуктов.

### 4. Анализ рекламных каналов

Для оценки источников привлечения пользователей использована модель **Last Click Attribution**.

Последнее маркетинговое касание пользователя перед установкой игры использовалось для определения рекламного канала, которому была атрибутирована установка.

На основе атрибуции проанализированы:

* количество новых пользователей по каналам;
* активность пользователей по каналам;
* конверсия в платящих пользователей;
* динамика показателей рекламных каналов.

### 5. Визуализация и интерпретация

Результаты SQL-запросов загружены в Python для построения графиков и визуального анализа динамики показателей.

На основе полученных результатов определены проблемные области и сформированы рекомендации с учётом их влияния на дерево метрик.

## Используемые инструменты

* **PostgreSQL** — хранение и анализ данных;
* **SQL** — расчёт метрик, объединение таблиц, фильтрация и агрегация данных;
* **Python** — дополнительный анализ и визуализация;
* **Psycopg2** — подключение к PostgreSQL из Python;
* **Pandas** — получение и обработка результатов SQL-запросов;
* **Seaborn** — визуализация данных;
* **Plotly** — построение интерактивных графиков.

## Результат

В результате проведён анализ динамики выручки мобильной игры и выполнена её декомпозиция по ключевым метрикам.

С помощью SQL определены изменения в пользовательской активности, монетизации, продажах продуктов и привлечении новых пользователей. Отдельно проведён анализ рекламных каналов с использованием **Last Click Attribution**.

На основании результатов анализа выявлены факторы, связанные с изменением выручки, и сформированы рекомендации по улучшению ключевых показателей.

* `report.docx` — аналитический отчёт с результатами исследования и рекомендациями.
