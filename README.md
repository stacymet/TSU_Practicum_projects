# Анализ факторов возврата кредита в срок

## О проекте

Учебный проект по анализу данных клиентов банка.

Задача исследования — определить, связаны ли семейное положение, количество детей, уровень дохода и цель кредита с вероятностью своевременного погашения кредита.

Результаты анализа могут использоваться при разработке и совершенствовании моделей **кредитного скоринга**, оценивающих платёжеспособность потенциальных заёмщиков.

## Цель исследования

Выявить категории клиентов и характеристики кредитов, связанные с различиями в своевременности погашения задолженности.

### Основные задачи

* изучить структуру и качество исходных данных;
* обработать пропущенные значения и дубликаты;
* привести данные к корректным типам;
* категоризировать данные для проведения анализа;
* исследовать зависимость возврата кредита в срок от количества детей;
* изучить связь между семейным положением и возвратом кредита;
* проанализировать влияние уровня дохода на своевременность погашения;
* определить, как цель кредита связана с вероятностью его возврата в срок;
* сформулировать выводы и рекомендации для бизнеса.

## Данные

В исследовании используется статистика о платёжеспособности клиентов банка.

### Основные признаки

* `children` — количество детей в семье;
* `days_employed` — общий трудовой стаж в днях;
* `dob_years` — возраст клиента;
* `education` — уровень образования;
* `education_id` — идентификатор уровня образования;
* `family_status` — семейное положение;
* `family_status_id` — идентификатор семейного положения;
* `gender` — пол клиента;
* `income_type` — тип занятости;
* `debt` — наличие задолженности по возврату кредитов;
* `total_income` — ежемесячный доход;
* `purpose` — цель получения кредита.

## Ход исследования

### 1. Предобработка данных

* изучение общей информации о датасете;
* обработка пропущенных значений;
* изменение типов данных;
* поиск и удаление дубликатов;
* обработка неявных дубликатов;
* категоризация данных для дальнейшего анализа.

### 2. Анализ зависимости возврата кредита от количества детей

Проверена связь между количеством детей у клиента и фактом своевременного возврата кредита.

### 3. Анализ семейного положения

Исследована зависимость между семейным статусом клиента и возвратом кредита в срок.

### 4. Анализ уровня дохода

Клиенты разделены на категории по уровню дохода, после чего проведено сравнение доли клиентов с задолженностью в разных группах.

### 5. Анализ целей кредитования

Исследовано, различается ли своевременность возврата кредитов в зависимости от цели займа.

Для анализа использованы группировки и сводные таблицы с помощью `groupby()` и `pivot_table()`.

### 6. Формулирование выводов

По результатам анализа определены группы клиентов с различающейся долей просрочек и сформулированы рекомендации для использования результатов в кредитной аналитике.

## Используемые инструменты

* **Python** — анализ и обработка данных;
* **Pandas** — очистка, преобразование, категоризация и группировка данных;
* **Jupyter Notebook** — выполнение и документирование исследования.
