# Анализ музыкальных предпочтений пользователей Москвы и Санкт-Петербурга

## О проекте

Учебный проект по анализу данных пользователей Яндекс Музыки.

В проекте исследуется, отличаются ли музыкальные предпочтения и активность пользователей из Москвы и Санкт-Петербурга. Исследование направлено на проверку распространённых представлений о различиях между двумя столицами на основе реальных данных.

## Задача

Проверить несколько гипотез о поведении пользователей Яндекс Музыки и определить, действительно ли город проживания и день недели связаны с активностью пользователей и их музыкальными предпочтениями.

### Гипотезы

1. Активность пользователей зависит от дня недели, причём в Москве и Санкт-Петербурге наблюдаются разные закономерности.
2. Музыкальные предпочтения пользователей различаются в зависимости от города и времени прослушивания: утром в понедельник и вечером в пятницу в Москве и Санкт-Петербурге популярны разные жанры.
3. Пользователи двух столиц предпочитают разные музыкальные жанры. В частности, проверяется предположение, что в Москве чаще слушают поп-музыку, а в Санкт-Петербурге — русский рэп.

## Данные

Для анализа используется датасет `yandex_music_project.csv`.

Датасет содержит информацию о прослушиваниях пользователей:

| Столбец  | Описание                   |
| -------- | -------------------------- |
| `userID` | идентификатор пользователя |
| `Track`  | название трека             |
| `artist` | имя исполнителя            |
| `genre`  | музыкальный жанр           |
| `City`   | город пользователя         |
| `time`   | время начала прослушивания |
| `Day`    | день недели                |

## Ход исследования

1. **Знакомство с данными**

   * изучение структуры датасета;
   * анализ типов данных;
   * проверка пропусков и дубликатов.

2. **Предобработка**

   * очистка данных;
   * приведение данных к необходимому виду;
   * подготовка датасета к дальнейшему анализу.

3. **Анализ активности пользователей**

   * сравнение количества прослушиваний по дням недели;
   * сравнение активности пользователей Москвы и Санкт-Петербурга.

4. **Анализ музыкальных предпочтений**

   * исследование популярных жанров;
   * сравнение предпочтений пользователей двух городов;
   * анализ музыкальных предпочтений в понедельник утром и пятницу вечером.

5. **Проверка гипотез**

   * сопоставление полученных результатов с исходными предположениями;
   * формулирование выводов на основе данных.

## Используемые инструменты

* **Python** — язык программирования для анализа данных.
* **Pandas** — загрузка, очистка, обработка и анализ данных.

## Результат

В ходе проекта проведён анализ поведения пользователей Яндекс Музыки из Москвы и Санкт-Петербурга и проверены гипотезы о различиях в их активности и музыкальных предпочтениях.

Исследование показывает, какие из распространённых представлений о двух столицах подтверждаются данными, а какие не находят подтверждения.
